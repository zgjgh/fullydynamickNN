\begin{abstract}
The kNN join is a core operation in high-dimensional analytics, with applications in vector databases, recommendation, anomaly detection, and data mining. Existing dynamic kNN join methods mainly handle one-sided updates, where either the query set or the reference set changes. We study exact fully dynamic kNN join, where both sets evolve through insertions and deletions and the materialized join result must remain correct after each update. This setting is important when neighborhood results are used for auditable analytics, deterministic downstream decisions, or exact maintenance before optional approximate serving layers. We propose \dualtree, a dual-index framework that maintains an \hdrtree on the query set and a \deltatree on the reference set, thereby aligning kNN-based row repair on the reference side and affected-query localization on the query side with the index structure best suited to each task. We further introduce a point-wise low-dimensional pruning stage at leaf nodes and derive a cost-aware model for selecting the pruning dimensionality. This model formalizes the trade-off between projection cost and pruning power, enabling near-optimal pruning without heuristic dimension selection. Experiments on eight real high-dimensional datasets show that \dualtree improves over strong one-sided baselines, and that the proposed cost-aware pruning provides substantial additional gains, reaching up to 2.65$\times$ speedup over the strongest baseline in our evaluation.
\keywords{kNN join \and fully dynamic data \and high-dimensional data \and RkNN search \and dimensionality reduction \and cost-aware pruning}
\end{abstract}
