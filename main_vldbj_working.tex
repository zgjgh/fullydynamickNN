\begin{abstract}
The kNN join is a core operation in high-dimensional analytics, with applications in vector\linebreak databases, recommendation, anomaly detection, and data mining. Existing dynamic kNN join methods mainly handle one-sided updates, where either the query set or the reference set changes. We study exact fully dynamic kNN join, where both sets evolve through insertions and deletions and the materialized join result must remain correct after each update. This setting is important when exact neighborhood relationships are required for auditable analytics or deterministic downstream decisions. We propose \dualtree, a framework built around a dual-index structure. This index supports efficient bidirectional kNN processing in high-dimensional spaces: kNN search from the query set to the reference set and RkNN search from the reference set back to the query set. The index also supports dynamic updates as either set changes. The framework further provides a dual-maintenance strategy that jointly maintains the index and the materialized kNN join table, thereby enabling efficient exact fully dynamic kNN join processing in high-dimensional spaces. We further introduce fine-grained low-dimensional pruning and a mathematical model for near-optimal dimensionality selection. Experiments on eight real high-dimensional datasets show that \dualtree and its pruning variants consistently outperform the baselines, achieving up to 2.65$\times$ speedup over the fastest baseline.
\keywords{kNN join \and fully dynamic data \and high-dimensional data \and RkNN search \and dimensionality reduction \and cost-aware pruning}
\end{abstract}
